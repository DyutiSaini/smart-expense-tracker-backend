# Smart Expense Tracker Backend

Backend API for the Smart Expense Tracker application built with Node.js, Express.js, MongoDB Atlas, and JWT Authentication.

## Features

* User Registration & Login
* JWT-based Authentication
* HTTP-only Cookie Management
* Expense CRUD Operations
* Protected Routes
* MongoDB Atlas Integration
* Error Handling & Validation

## Tech Stack

* Node.js
* Express.js
* MongoDB Atlas
* Mongoose
* JWT
* bcrypt
* Render

## API Endpoints

### Authentication

* `POST /api/v1/user/register`
* `POST /api/v1/user/login`
* `POST /api/v1/user/logout`

### Expenses

* `POST /api/v1/expense`
* `GET /api/v1/expense`
* `DELETE /api/v1/expense/:id`
